С момента первого бекапа от 8 октября изменилось следующее:
Сайт стал легче загружаться.
Уменьшились размер 39 изображений примерно на 83%, сохранив оригиналы. Карта, помощник FAQ и другие тяжёлые элементы загружаются по мере необходимости. В локальных замерах при первом открытии главной страницы передавалось примерно на 80% меньше данных. Общий стиль сайта сохранено.
Исправилено вход и защиту аккаунтов.
Вход теперь проверяет настоящую учётную запись. Удалено возможность войти с произвольными данными через демонстрационный режим. Закрыто возможность задать пароль чужому существующему аккаунту. Исправлено завершение входа, обработку истёкших сессий и хранение новых длинных паролей.
Убрали Telegram и ЭЦП.
Регистрация и вход работают через email и пароль. Для запуска этих функций больше не нужны Telegram-бот и NCALayer.
Исправлено прохождение тестов.
Ответы, последовательность разделов, время и расчёт результатов контролируются сервером. Прогресс сохраняется при перезагрузке страницы. Исправленон зависание на сохранении результата и повторную отправку после сбоя связи. Ошибка загрузки результатов больше не выбрасывает пользователя из личного кабинета.
Разделено доступ сотрудников.
Администратор управляет правами и подразделениями. Центральные сотрудники работают со всеми заявками, территориальные — только со своим подразделением. При изменении прав старые сессии сотрудника завершаются.
Добавилено полноценная обработка заявок.
Через панель можно назначать подразделение и ответственного, менять статус, оставлять служебные заметки и отправлять сообщения кандидату. Служебные заметки кандидату не показываются. История сохраняет, кто, когда и что изменил.
Упрощено поиск и получение ответа.
Добавлено поиск, фильтры и переход между страницами списков. Сотрудники могут работать со всеми записями, а не только с первыми 200–300. Посетитель может проверить статус обращения по коду, а владелец после входа — прочитать личный ответ.
Подготовили базы и инструменты сопровождения.
Разделено учётные записи для ежедневной работы сайта и изменения устройства базы. Добавлено ограничения против некорректных записей. Создано коллекцию Bruno для проверок. Резервные копии проверили восстановлением: прежние данные сохранились.
