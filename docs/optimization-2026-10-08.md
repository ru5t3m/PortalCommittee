# Оптимизация портала — 8 октября 2026

## Изменения по пунктам 1–5

1. Обновлены Next.js до 16.4.0, React до 19.3.0 и связанные зависимости.
   Исправлены известные уязвимости производственных зависимостей интерфейса.
   На сервере обновлены FastAPI, Starlette, cryptography и python-multipart.
   Для JWT используется PyJWT вместо python-jose с уязвимой зависимостью ecdsa.
   Формат токенов и проверка разрешённого алгоритма сохранены.
2. Настроены ESLint, проверка типов и GitHub Actions. Добавлены браузерные
   проверки русской и казахской версий, изображений, FAQ, карты, мобильного меню,
   входа, этапов поступления, режима доступности и начала психотестирования.
   Серверные тесты проверяют регистрацию, вход, обновление и завершение сессии,
   обращения, сохранение прогресса и результатов, изоляцию пользователей,
   недопустимые данные и отказ для неверных JWT.
3. 39 изображений переведены в WebP: 36 260 828 → 6 033 118 байт, сокращение 83%.
   Оригиналы сохранены в `apps/web/assets/source-media`, исключены из Docker-образа.
   Изображения тестовых заданий сохранены без преобразования.
   Фотографии и эмблемы на информационных страницах используют Next Image,
   размеры и отложенную загрузку. Размер `public`: 45,05 → 16,22 MiB.
4. Информационные страницы ru/kk и направления деятельности формируются при
   сборке с интервалом обновления кеша один час. Ссылки `?stage=` продолжают
   выбирать этап поступления. Приватные страницы и админ-панель используют
   `no-store`; неизвестные языки и направления возвращают 404.
5. Удалён Framer Motion; анимация появления реализована через CSS и
   IntersectionObserver с поддержкой уменьшенного движения. FAQ загружается
   при открытии и сохраняет переписку после закрытия. Стили карты загружаются
   только в контактах. В Header передаётся только необходимая часть словаря.
   Разделы основного меню предварительно загружаются при наведении или фокусе
   на ссылку, а не все одновременно при открытии страницы.

## Оставшиеся ограничения

Полный npm-аудит сообщает о семи пакетах инструментов разработки в цепочках
Tailwind CSS 3 и eslint-config-next. Причина —
[уязвимость braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)
при обработке глубоко вложенных шаблонов файлов. Исправленная версия braces
на дату проверки отсутствует. Эти пакеты отсутствуют в производственных
зависимостях сайта; аудит инструментов следует повторить после исправления
вышестоящей библиотеки.

Включённый ранее демонстрационный режим входа сохранён. Браузерные тесты входа
проверяют этот режим; серверные тесты отдельно проверяют реальную авторизацию.
FAQ в браузерных тестах использует контролируемые ответы API, включая ошибку
503. Реальные LLM, Telegram, NCALayer и внешняя инфраструктура ЭЦП не подключены
и не проверены этим этапом.

## Методика замеров

До изменений измерялась сохранённая версия `backup/2026-10-08`, после —
производственная сборка в том же локальном Docker. Для каждого адреса выполнялись
три загрузки в новых браузерных контекстах Microsoft Edge, окно 1365×768.
В таблице используются медианы. Скрипт: `apps/web/scripts/measure-pages.mjs`.
Повторный запуск из `apps/web`: `npm run measure -- .verification/pages.json`.

Объём — `encodedBodySize` из браузерного Performance API для HTML и ресурсов
до завершения начальной загрузки; включает автоматически загруженные ресурсы.
Ресурсы внешних серверов без Timing-Allow-Origin могут учитываться как ноль.
Сеть и процессор не замедлялись, поэтому времена не характеризуют мобильную
загрузку через интернет. Оптимизация картинок и отложенная загрузка уменьшают
начальный объём страницы; полный объём после прокрутки будет больше.
